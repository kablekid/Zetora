# Languages and themes

Zetora ships in **English** and **አማርኛ (Amharic)**, and in **Light**, **Dark** and **System** themes.
This page explains how both work and how to extend them.

> **Translation review.** The Amharic copy was written by an AI assistant and has **not** been reviewed by a native
> speaker or an Ethiopian teacher. Treat it as a strong first draft: have it proof-read before launch (see
> [Reviewing the translation](#reviewing-the-translation)). Course content (subjects, units, summaries, questions,
> PDFs) is **not** translated automatically — administrators write it in whatever language they teach in.

## For students

* **Language** – header menu (🌐 EN / አማ), the profile menu, or **Settings → Language**. The choice is remembered in a
  cookie and, when you are signed in, on your profile, so it follows you to other devices.
* **First visit** – the browser's `Accept-Language` header is used (`am*` → Amharic, everything else → English).
* **Theme** – the sun/moon button in every header, the profile menu, or **Settings → Appearance** (Light / Dark /
  System). *System* follows the phone or computer.

## How it works

```
src/i18n/
  config.ts              locales, cookie name, which message groups are sent to the browser
  core.ts                createTranslator(): {var} interpolation, plurals, <tag> rich text
  format.ts              dates, relative times, durations, numbers, greeting (Intl, Africa/Addis_Ababa)
  server.ts              getLocale(), getT(ns), getFormat(), pageTitle() — for Server Components
  client.tsx             <I18nProvider>, useT(ns), useFormat(), useLocale() — for Client Components
  rich.tsx               <Rich> (bold/links inside a sentence) and <Slots> (word order differs per language)
  server-text.ts         lookup for text that comes from the server (validation, action results, DB errors)
  messages/
    en/…                 the source of truth, one file per area (common, nav, auth, learn, quiz, admin/…)
    am/…                 typed as `typeof en`, so a missing or extra key is a compile error
    am/server-text.ts    English sentence → Amharic, for text the server produces
```

* **Resolution order**: `zetora-locale` cookie → `Accept-Language` → English. Signing in restores the language saved on
  the profile when there is no cookie.
* **Server components** call `const t = await getT('learn')`; **client components** call `const t = useT('learn')`.
  Both are type-checked: `t('header.unit', { n: 3 })` only compiles for keys that exist.
* **Only what the browser needs is sent to it.** `CLIENT_NAMESPACES` (common, nav, auth, subjects, learn, quiz, charts,
  notifications, search, settings, viewer) go to every page; the `admin` group is sent only to administrators;
  marketing, legal, dashboard, exams, progress … are rendered on the server and never shipped.
* **Plurals** are leaves shaped `{ one: '{count} unit', other: '{count} units' }`, chosen with `Intl.PluralRules`.
  Amharic uses the same two forms.
* **Dates and numbers** use `Intl` with `en-GB` / `am-ET` in the Africa/Addis_Ababa time zone. Digits stay Latin (0-9)
  in both languages because that is what Ethiopian learners see in exams and textbooks. The Gregorian calendar is used;
  an Ethiopian-calendar option would be a small change in `format.ts`.
* **Text that originates on the server** (zod messages, `ActionResult.error`, Postgres `RAISE EXCEPTION`) is sent in
  English and translated by looking the sentence up in `am/server-text.ts`. The `toast` helper in `src/lib/toast.ts`,
  `<Field>` and `<FormError>` do this automatically. A key ending in `…` matches by prefix.
* **Notifications created by the database** (new subject / material / quiz / exam) store the content's name in
  `notifications.params`, and the UI renders "New subject: {name}" from the reader's own language. Announcements written
  by an administrator are shown exactly as written.
* **Fonts**: Inter plus *Noto Sans Ethiopic* (variable). The Ethiopic file is only downloaded when a page contains
  Ethiopic characters (`unicode-range`). `:lang(am)` rules loosen line-height and remove negative letter-spacing, which
  clips Ethiopic syllables.
* **Right-to-left**: both languages are left-to-right. Layouts still use logical utilities (`ps-*`, `me-*`,
  `text-start`, …), so adding an RTL language later would not need layout changes.

## Adding or changing text

1. Add the key to `src/i18n/messages/en/<area>.ts`.
2. Add the Amharic string with the **same key and the same `{placeholders}` / `<tags>`** in `am/<area>.ts`.
   TypeScript fails the build if you forget.
3. Use it: `t('area.key', { name })`.

If the text comes from a server action, validator or database function, add `'English sentence': 'አማርኛ'` to
`am/server-text.ts` instead.

### Checks

| Command | What it checks |
| --- | --- |
| `npm run typecheck` | `am` has exactly the keys of `en` |
| `npm run check:i18n` | placeholders and `<tags>` match in both languages, array lengths match, no empty / untranslated Amharic, every message the server can send has an Amharic entry |
| `npm run i18n:untranslated` | scans the source for hard-coded English in JSX text, `aria-label` / `placeholder` / `title` / `alt`, toasts and error strings |
| `E2E_FLOWS=flow-i18n.mjs npm run e2e` | real-browser check of the Amharic UI, language switching, theme switching and phone layouts |

## Adding another language

1. Add the code to `LOCALES` and `LOCALE_META` in `config.ts` (and to the `profiles_locale_check` constraint in a new
   migration).
2. Copy `messages/am` to `messages/<code>`, translate it and register it in `messages/index.ts`.
3. Add a font if the script needs one (see `globals.css`), and run the checks above.

## Reviewing the translation

* Terminology used (change it in one place, the dictionaries): subject **ትምህርት**, unit **ምዕራፍ**, topic **ርዕስ**,
  summary **ማጠቃለያ**, learning materials **የመማሪያ ቁሳቁሶች**, quiz **ኩዊዝ**, exam **ፈተና**, mock exam **የሙከራ ፈተና**,
  progress **እድገት**, bookmark **ዕልባት**, notifications **ማሳወቂያዎች**, settings **ቅንብሮች**, administrator **አስተዳዳሪ**.
* Register: polite plural imperative (ይግቡ, ይመዝገቡ, ይቀጥሉ). The brand name **Zetora** stays in Latin script.
* Good places to start a review: `messages/am/marketing.ts` and `auth.ts` (first impression), `quiz.ts` and `exams.ts`
  (exam-day wording), `legal.ts` (privacy / terms — have a lawyer review the English first).
